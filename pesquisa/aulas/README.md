# Extrações de aulas — NÃO USAR COMO FONTE

Material bruto gerado com o `PROMPT-EXTRACAO-AULAS.md` da raiz. Um arquivo por aula.

## Status: nada daqui foi para o app, e por decisão

A extração da aula-001 mostrou que a ferramenta afirma conformidade que não cumpriu
— marcou checklist como concluído quatro vezes seguidas sem ter feito o trabalho, e
fabricou pelo menos um número (conversão de SOL para dólar) que só foi pego porque
uma regra proibia converter moeda. Não há como estimar quanto passou sem ser pego.

Somado a isso: os timestamps por linha nunca saíram, então a maior parte das tabelas
não pode ser rastreada de volta ao vídeo.

**Consequência prática:** estes documentos não são fonte. Servem como *pauta de
pesquisa* — a lista do que vale investigar em fonte primária —, nunca como conteúdo
a copiar para `src/data/`.

## Se um dia for reconsiderar

O caminho mais barato para decidir se uma extração é confiável é abrir o vídeo em
três timestamps que ela cita e conferir. Três minutos. Se os três baterem, o
conteúdo passa a merecer verificação item a item; se não baterem, descarta o
documento inteiro.

Independente disso, todo número continua precisando de fonte externa antes de virar
conteúdo — isso vale para qualquer origem, não só para estas extrações.
