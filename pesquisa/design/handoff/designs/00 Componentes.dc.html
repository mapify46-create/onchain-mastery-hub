GradeDe100

Relação: probabilidade e taxa de acerto

100 quadrados, grupos coloridos, legenda e a frase "de cada 100…". Frequência natural é mais fácil de entender que porcentagem. Exemplo: o melhor detector de rug, modulo6.js › secoes › detector (estimativa reconstruída, como o arquivo avisa).

Normal · duas grades lado a lado (empilham no celular)

Celular · 390px

Mesmo desenho: a grade tem no máximo 230px de largura, cabe inteira. As duas grades empilham.

Foco · Reduzir movimento

Estático: não recebe foco, não anima. Quando o valor vem de um controle (ex.: taxa de acerto do simulador), os quadrados só trocam de cor, sem transição.

Alternativa em texto

A legenda é a alternativa: "95 — são rug mesmo; 5 — não eram rug".

Dados que recebe 
montarGradeDe100({
  id,
  frase,                                   // "De cada 100 tokens marcados como rug, cerca de 95 são rug mesmo."
  grupos: [{ rotulo, quantidade, cor }],   // soma = 100; o resto vira "#1F2733"
  fonte?
})
Cores permitidas: #EF4444 (ruim) · #22C55E (bom) · #F59E0B (atenção) · #7C3AED (o que o modelo pega) · #1F2733 (resto).
Preenche da esquerda para a direita, de cima para baixo, na ordem dos grupos.

BarrasNaMesmaEscala

Relação: proporção

2–4 barras com rótulo, valor e partes: sólido (dinheiro real), tracejado (número no papel), listrado (a parte que interessa). Exemplo: market cap × liquidez do token inventado de modulo6.js › secoes › numeros-que-enganam.

Normal · desktop e celular (mesmo layout)

Celular · 390px

Idêntico: as barras são porcentagem da largura do card. Rótulo e valor quebram em duas linhas se faltar espaço.

Foco · Reduzir movimento

Estático. Quando ligado a uma calculadora, a largura muda com transition: width 120ms, que vai a zero com "reduzir movimento".

Alternativa em texto

"{{ barras.alternativa }}"

Dados que recebe 
montarBarrasNaMesmaEscala({
  id, legenda?, exemploInventado?: true,
  maximo,                                    // valor que ocupa 100% da largura
  barras: [{ rotulo, valor, exibicao, nota?,
             partes: [{ rotulo, valor, estilo: 'solido'|'tracejado'|'listrado', cor? }] }]
})
Estilos: solido = fundo #7C3AED (ou cor) · tracejado = borda 2px dashed #9AA7B4, sem fundo · listrado = repeating-linear-gradient 135° #22D3EE 3px/3px.
Alternativa em texto: "rótulo — exibição (parte: valor; …)" por barra.

A <ol> com <time> já é a alternativa; o intervalo é lido como texto ("4 anos e 9 meses depois").

Dados que recebe (compatível com a atual)

  id, titulo, descricao?, nota?,

Espaço entre marcos = 24px + 1,2px por mês, limitado a 96px. Rótulo do intervalo: "N anos e M meses depois" / "M meses depois" / "menos de 1 mês depois". Datas só com ano contam como 1º de julho; só com mês, como dia 1.

Animacao

Relação: causa → efeito no tempo

Palco + legenda (até 12 palavras) + Tocar/Pausar/Voltar/Avançar + barra de cenas. Cada cena é um estado dos elementos do palco; o motor interpola entre cenas. Exemplo curto (3 cenas) do que será a Animação 1 — Pool x·y = k.

Normal · desktop e celular (palco 16:9, largura total)

{{ anim.tokensTexto }}
{{ anim.solTexto }}
tokensSOL
x · y = k

{{ anim.legenda }}

cena {{ anim.numero }} de {{ anim.total }}

Foco

Tocar

Espaço = tocar/pausar; ← → = cena anterior/seguinte; cada segmento da barra é um botão com nome ("Cena 2: Você vende").

Reduzir movimento

Não toca sozinho: "Tocar" vira "Próxima cena" e cada cena aparece parada, sem transição. O conteúdo é o mesmo — só muda o ritmo, que passa a ser do aluno.

Alternativa em texto

As legendas em ordem, numa <ol> recolhida em "Ler como texto".

Dados que recebe 
montarAnimacao({
  id, titulo, duracaoPorCena?: 4000,
  elementos: [{ id, tipo: 'barra'|'caixa'|'seta'|'texto', rotulo, estilo }],
  cenas:     [{ rotulo, legenda (≤ 12 palavras), estados: { [elementoId]: { altura?, x?, y?, opacidade?, texto? } } }]
})
Motor: troca de cena = aplicar os estados com transition 400ms ease; autoplay avança a cada duracaoPorCena.
Com prefers-reduced-motion: transition none, sem autoplay, "Tocar" vira "Próxima cena".
Total 20–40 s, 5–10 cenas. Estado não vai para o localStorage.
